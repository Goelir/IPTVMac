IPTVMac / פלטפורמות

IPTV ב-Windows,בלי משקל מיותר.

בנוי ב-Flutter עם מעטפת C++ קטנה. בערך 27MB, נוח למקלדת ולעכבר, וכמעט לא צורך מעבד בזמן שהוא פתוח.

הורדה ל-Windows

גרסה 1.0.5 · מתקין 27MB · Windows 10 ו-11, ‏64 ביט

כל ההורדות

התקנה

התקנה

Windows 10 או 11, ‏64 ביט.

  1. פותחים את IPTVMac-Windows-setup.exe. הוא מתקין למשתמש שלכם בלבד ולא צריך הרשאות מנהל.
  2. ייתכן ש-Windows יגיד שהגן על המחשב: האפליקציה עוד לא חתומה בתעודה בתשלום. בוחרים More info ואז Run anyway.
  3. פותחים את IPTVMac ומוסיפים כניסת Xtream Codes או קישור M3U. רווח עוצר, החיצים מדלגים, F ממלא את המסך.

קלה בכוונה: בערך 27MB להורדה, ובזמן שהיא רק פתוחה היא כמעט לא צורכת מעבד. העדכונים ידניים בינתיים: האפליקציה מודיעה כשיצאה גרסה חדשה, ומריצים את המתקין החדש מעל הישן.

מה מקבלים

  • קודם כל מקלדת.

    רווח עוצר, החיצים מדלגים, F ממלא את המסך. וכל פקד נמצא גם במרחק לחיצה.

  • כל הספרייה, בחיפוש תוך כדי הקלדה.

    שידור חי, סרטים וסדרות מ-Xtream Codes או M3U, עם חיפוש בקטגוריה, בחלק או בכל מקום.

  • הורדות לצפייה בלי רשת.

    שומרים סרטים ופרקים ומנגנים אותם בלי חיבור.

שאלות

למה Windows SmartScreen מזהיר?

האפליקציה עוד לא חתומה בתעודת חתימת קוד בתשלום. בוחרים More info ואז Run anyway. קוד המקור פתוח ב-GitHub.

צריך הרשאות מנהל?

לא. המתקין מתקין למשתמש שלכם בלבד. יש גם zip נייד שרץ בלי התקנה.

איך מתעדכנים?

האפליקציה מודיעה כשיוצאת גרסה חדשה. מריצים את המתקין החדש מעל הישן, והרשימות וההגדרות נשארות.

IPTVMac הוא נגן. הוא לא כולל ולא מארח תוכן כלשהו; השתמשו רק במקורות שמותר לכם לגשת אליהם. IPTVMac אינו קשור ל-iptv-org.

נגני IPTV אחרים. IPTVMac פועל ב-Mac, ב-Windows, ב-iPhone וב-iPad, ב-Android וב-Android TV. אם אתם צריכים Linux או משהו אחר: IPTVnator חינמי ובקוד פתוח ופועל גם ב-Windows וב-Linux. VLC יכול לפתוח רשימת M3U ישירות. ל-IPTV Smarters Pro יש אפליקציית שולחן עבודה ל-macOS.
