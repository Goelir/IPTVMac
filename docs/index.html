One app, four ways to install.

The same player, the same 31 languages, no account. Each version is written in the language that suits its platform, not squeezed into one shared shell, and the video itself is decoded by the same compiled libmpv engine everywhere. Pick your device.

Mac

Apple Silicon, macOS 14 or later. Written in Swift and SwiftUI, Apple's own language and toolkit.

  1. Paste the one-line command in Terminal, or open IPTVMac.dmg and drag the app to Applications.
  2. Add your Xtream Codes login or M3U link.
  3. The app updates itself.
Download the DMGIPTVMac for Mac

Windows

Windows 10 or 11, 64-bit. Written in Dart with Flutter, with a small C++ shell. Light on memory and processor.

  1. Download the installer. It installs for your user only, with no administrator rights.
  2. If Windows SmartScreen warns (the app is not signed with a paid certificate yet), choose More info, then Run anyway.
  3. Add your source. Space pauses, the arrows seek, F fills the screen.
Download the installerIPTVMac for Windows

Android phone and tablet

Android 8 or later. Written in Dart with Flutter, with a Kotlin layer for the Android system features.

  1. Download the arm64-v8a file (it suits almost every phone).
  2. Open it and allow installs from your browser or Files app.
  3. Add your source. A banner tells you when a new version is out; Update now installs it from the app.
Download the APKIPTVMac for Android

Android TV, Google TV, Fire TV

First TV version: remote control, no touch screen. Same Flutter and Kotlin code as the phone, with a layout built for the remote.

  1. Install the Downloader app on the TV and open it.
  2. Type the address of the file (below). Try the 32-bit file first; if the TV says it is not compatible, use the 64-bit one. A USB stick works too.
  3. Allow Downloader to install apps, then install and open IPTVMac. OK selects, Back goes up, hold Back to close.

No playlist yet?

IPTVMac is only a player, so it needs a playlist. If you do not have a provider, iptv-org is a free, independent open source project that publishes M3U playlists of publicly available channels from around the world. In IPTVMac choose M3U, give it a name and paste the link below.

https://iptv-org.github.io/iptv/index.m3u

IPTVMac is not affiliated with iptv-org. Whether a stream is available, and whether you may watch it, depends on the channel and on your country: use only what you are allowed to.

Questions

What is IPTVMac?

IPTVMac is a free, open source IPTV player for Mac, Android phones and tablets, and Android TV, Google TV and Fire TV (and an iPhone and iPad app on the App Store). It plays Xtream Codes and M3U sources with a built-in mpv player, instant search, subtitles, Picture in Picture, catch-up, downloads and an interface in 31 languages.

Does IPTVMac include channels or a subscription?

No. IPTVMac is only a player. It does not include or host any channels, movies or series. You add a source from a provider you are authorized to use. If you have none, the independent open source project iptv-org publishes free playlists of publicly available channels; see the link on this page.

Does it work with Xtream Codes and M3U?

Yes. For Xtream Codes you enter the server address, username and password from your provider. For M3U you enter a name and the playlist link.

Which Macs are supported?

Apple Silicon Macs (M1 or later) with macOS 14 or later. Intel Macs are not supported.

Is there an iPhone, iPad or Android version?

Android: yes. Download the APK from GitHub Releases (https://github.com/Goelir/IPTVMac/releases/tag/android-v1.0.9); it has a touch player, Picture in Picture, sound with the screen off and downloads for offline viewing, and needs Android 8 or later. Android TV, Google TV and Fire TV: the same release has a 32-bit and a 64-bit file for TVs (remote-control friendly, no downloads on TV, first version, installed directly with the Downloader app or from a USB stick; there is no store listing yet). iPhone and iPad: yes, the app is on the App Store (https://apps.apple.com/app/id6821761790) and it is completely free: no ads, no subscription, no in-app purchases. It needs iOS 17 or later and has the same 31 languages and the same no-account, no-tracking design. All share the engine, the 31 languages and the no-account, no-tracking design of the Mac app, and the source is in the same GitHub repository.

Is the App Store version different from the one on GitHub?

It is the same iPhone and iPad app and the same code. The App Store version installs with one tap and updates itself after Apple has reviewed each version; GitHub is usually a little ahead. If you build it from GitHub yourself you sign it with your own Apple ID (a free account lasts 7 days, a paid one a year) and update by building again. Mac, Windows and Android are not in an app store: the files on GitHub are the only versions.

Is IPTVMac free?

Yes. It is free and open source under the GPL-3.0 license, with no ads and no tracking.

Why does macOS block the app, and how do I open it?

Versions before 0.9.1 are not notarized by Apple, so macOS blocks a copy that was downloaded in a browser. From version 0.9.1, releases are signed with an Apple Developer ID and notarized, and the DMG opens with a normal double-click. To fix an older copy, install the latest release (the DMG, or the one-line command above, which works for every version), or open System Settings, Privacy and Security, and choose Open Anyway.

Does IPTVMac have Picture in Picture?

Yes. A floating window stays on top of other apps and across Spaces while you browse for something else.

Can I watch past programs (catch-up)?

Yes, on channels where your provider supports catch-up. Pick a program from the guide.

Is it safe to use?

The source code is public. Updates come from GitHub Releases and are checked against a SHA-256 checksum. Account passwords are stored in the app's local database, readable only by your user.
