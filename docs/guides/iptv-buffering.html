IPTV keeps buffering? What to check

Most buffering comes from the provider or the network, not the player. Close other players that use the same login, try a wired connection, compare a few channels, and on the Mac raise the network buffer in Settings.

One connection at a time

Many IPTV accounts allow a single connection (max_connections). A second player, another device or a running download on the same login can make the stream stall. Close the others and try again.

The network

A steady connection matters more than a fast one. If you can, try a cable instead of Wi-Fi, or move closer to the router, and see whether the stalls stop.

The provider

If every channel buffers, or only at busy evening hours, the problem is usually the provider's server. If one channel buffers in IPTVMac and also in another player, it is that stream.

Player settings

  • On the Mac, Settings has a Network buffer: Small, Normal or Large. A larger buffer helps on a slow or unstable connection.
  • IPTVMac reconnects a dropped live stream by itself, so a short drop does not need a restart.

Still stuck?

The support page explains how to report a problem without sharing your login.
