How to add Xtream Codes IPTV on a Fire TV

Install the Downloader app on the TV, use it to install IPTVMac, then open IPTVMac and enter the server address, username and password from your provider.

What you need

A Fire TV, Android TV or Google TV device with Android 8 or later (on Fire TV that means Fire OS 7 or later), and the Xtream Codes login from your provider: a server address, a username and a password. IPTVMac does not provide any channels.

Install IPTVMac

  1. On the TV, install the Downloader app (on Fire TV from the Amazon store, on Android TV and Google TV from Google Play) and open it.
  2. Type the address of the 32-bit TV file from the Android TV page. If the TV says the file is not compatible, use the 64-bit file instead.
  3. Allow Downloader to install apps when the TV asks, then install and open IPTVMac.

Add your login

  1. Choose Xtream Codes and fill in a name, the server address, the username and the password with the remote.
  2. Select Test connection, then Save and sync. IPTVMac downloads your live channels, movies and series once and keeps them on the TV.

Using the remote

  • OK selects, Back goes up one level, and holding Back closes the app.
  • Updates are manual for now: install the new TV file over the old one; your sources stay.
